## Anti-patterns (each one bit something this session)

| Do not | Because |
|---|---|
| Run bare `bun test` | A preload guard blocks it. Use `bun run test`, which filters to `.test.js` and routes `.test.cjs` to `test:repository-compat`. |
| Trust an rc or a green-looking log without a summary line | A test file's `process.exit(0)` can end a whole run with rc=0 (issue #45). Read `Ran N tests across M files` and check M. |
| Assert that a config contains a literal you also wrote into it | That is a tautology, not a gate. It is why the verifier's `--from` drifted unnoticed for weeks. Derive expected values from the authority (e.g. the pin in `package.json`). |
| Assume a fix to `scripts/*.js` affects the perf job | It runs a pinned harness checkout, not PR head. |
| Edit files while a gate is running | A green result binds to the tree it ran against. |
